Manage MTG eBay Listings

This page provides management actions for the eBay Sandbox account.

Delete a Sandbox listing

You no longer need to know the eBay Item ID for every listing.

Use the protected GitHub Actions workflow and choose one of these identifiers:

  • ITEM_ID: use the eBay Item ID if you know it.
  • SKU: use the program SKU, such as PIP-11-NORMAL-NM, for listings created by this program.
  • TITLE: use the exact eBay listing title for older listings that do not have a program SKU.

For SKU and title searches, the workflow retrieves your active Sandbox fixed-price listings, finds the matching listing, and then ends it. If more than one listing matches, nothing is deleted.
